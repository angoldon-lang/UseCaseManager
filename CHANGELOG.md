# Novità

## 2.0.0 — 9 novembre 2026
- L'applicazione è ora solo **standalone** (server Linux): rimossa la versione SharePoint.
- **Versione visibile** nell'app (in basso) con data di build e le novità di ogni rilascio.
- **Aggiornamento semplice** sul server: `sudo ucm-update` (backup automatico e ritorno alla versione precedente se qualcosa non va).
- Gestione utenti dalla pagina web (solo amministratori).
- Nuovo campo facoltativo **Sales di riferimento**; **fatturato del cliente a scaglioni**.
- **Elaborazione dei testi con l'AI** a partire da appunti (facoltativa, richiede una chiave API sul server).
- Nuovo aspetto con i colori e il logo AD Consulting.
